# 이훤의 공부 기록

개발 공부 과정과 배운 내용을 기록하기 위한 정적 블로그입니다. GitHub Pages에서 별도 빌드 과정 없이 바로 사용할 수 있습니다.

## 로컬에서 보기

`index.html`을 브라우저에서 열거나, 간단한 정적 파일 서버를 실행하세요.

```powershell
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속합니다.

## 글 수정하기

현재 예시 글은 `index.html`의 `.post-card` 요소로 구성되어 있습니다. 글 카드의 제목, 설명, 날짜, 분류를 원하는 내용으로 바꾸면 됩니다. 검색 대상 키워드는 각 카드의 `data-search` 속성에 추가할 수 있습니다.

연락처 이메일 `hello@example.com`도 실제 주소로 교체해 주세요.
